# Q1 2026「新春焕新季」活动brief

## 活动基本信息
- 活动名称：新春焕新季
- 活动时间：2026-02-15至2026-03-31
- 活动目标：新增用户15万+，GMV突破500万，用户留存率提升至70%

## 目标受众
- 核心人群：18-35岁都市青年（占比60%）
- 次要人群：36-45岁家庭用户（占比30%）
- 边缘人群：学生群体（占比10%）

## 核心策略
1. 裂变拉新：邀请好友得50元优惠券（双方均可使用）
2. 促活转化：每日签到领积分，积分可兑换实物奖品或现金抵扣
3. 留存提升：针对老用户推出「焕新会员」专属权益

## 成功指标
- 新增用户数：≥15万
- GMV：≥500万
- 活动参与率：≥30%（基于DAU）
- 分享率：≥15%（参与用户中）
