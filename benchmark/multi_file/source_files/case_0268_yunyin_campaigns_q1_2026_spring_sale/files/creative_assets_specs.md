# Q1 2026「新春焕新季」活动创意资产规范

## 资产类型与要求
### 1. 抖音信息流广告
- 视频时长：15s/30s/60s
- 分辨率：1080x1920（竖屏）
- 格式：MP4
- 内容要求：突出活动主题、优惠信息、CTA按钮
- 截止日期：2026-02-10
- 负责团队：设计部视频组

###2. 小红书KOL帖子
- 图文：3-9张图片（正方形/竖屏）+ 500-800字文案
- 视频：60s以内，竖屏
- 品牌元素：需包含品牌logo（右下角，大小不超过10%）、活动slogan
- 截止日期：2026-02-12
- 负责团队：内容部小红书组

###3. 微信朋友圈广告
- 图片：1080x1920（竖屏）或1080x1080（正方形）
- 文案：不超过200字，含emoji
- CTA按钮：「立即参与」或「了解更多」
- 截止日期：2026-02-13
- 负责团队：设计部平面组

###4. 线下快闪店物料
- 海报：A0尺寸（841x1189mm）
- 展架：X展架（60x160cm）
- 宣传单页：A5尺寸
- 品牌要求：严格遵循2026版品牌手册（附件2）
- 截止日期：2026-02-14
- 负责团队：设计部线下组

## 审核流程
1. 资产初稿完成后提交至活动负责人
2. 活动负责人在24小时内反馈修改意见
3. 最终版需经品牌部审核通过后方可使用

附件：1. 活动slogan清单；2. 2026版品牌手册
