# API 文档 - inventory-service

## 概述

本文档描述inventory-service的所有API端点。

### 基础信息

- **基础URL**: https://api.example.com/v1
- **认证方式**: Bearer Token
- **响应格式**: JSON

## 认证

所有请求都需要在Header中包含认证token:

```
Authorization: Bearer {token}
```

## API 端点

### 1. 获取Resource列表

**请求**
```
GET /api/orders?page=1&limit=20&status=active
```

**响应**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [...],
    "total": 100,
    "page": 1,
    "limit": 20
  }
}
```

### 2. 创建Resource

**请求**
```
POST /api/orders
Content-Type: application/json

{
  "name": "item name",
  "description": "item description"
}
```

**响应**
```json
{
  "code": 201,
  "message": "created",
  "data": {
    "id": "uuid",
    "name": "item name",
    "createdAt": "2024-02-10T10:00:00Z"
  }
}
```

### 3. 获取Resource详情

**请求**
```
GET /api/orders/{id}
```

**响应**
```json
{
  "code": 200,
  "message": "success",
  "data": {...}
}
```

## 错误处理

| 状态码 | 含义 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器错误 |
