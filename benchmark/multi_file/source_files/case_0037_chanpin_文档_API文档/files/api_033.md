# API 文档

## 基础信息
- **API版本**: v1
- **基础URL**: https://api.example.com/v1
- **认证方式**: Bearer Token
- **响应格式**: JSON

## 端点列表

### 1. 获取产品列表
```
GET /products
```

**请求参数:**
- `page` (可选): 页码，默认1
- `limit` (可选): 每页数量，默认20
- `status` (可选): 产品状态过滤

**响应示例:**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 100,
    "page": 1,
    "list": [
      {
        "id": 1,
        "name": "产品A",
        "status": "active",
        "created_at": "2024-01-01T00:00:00Z"
      }
    ]
  }
}
```

### 2. 创建产品
```
POST /products
```

**请求体:**
```json
{
  "name": "新产品",
  "description": "产品描述",
  "category": "category_name"
}
```

**响应:**
- 200: 创建成功
- 400: 参数错误
- 401: 未认证
- 403: 无权限

## 错误代码

| 代码 | 含义 |
|-----|-----|
| 0 | 成功 |
| 1001 | 参数验证失败 |
| 1002 | 资源不存在 |
| 1003 | 权限不足 |
