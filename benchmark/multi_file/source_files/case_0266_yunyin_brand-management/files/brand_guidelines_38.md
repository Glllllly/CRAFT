# Brand Guidelines - Version 38

## Brand Identity

### Logo
- Primary logo: product_logo_primary.png
- Secondary logo: product_logo_secondary.png
- Usage guidelines: Minimum 50px width
- Clear space: 10px minimum

### Color Palette
- Primary: #065A82 (Deep Blue)
- Secondary: #02C39A (Teal)
- Accent: #F96167 (Coral)
- Neutral: #1E293B (Dark), #F1F5F9 (Light)

### Typography
- Headlines: Calibri Bold, 36-44pt
- Body: Calibri Regular, 14-16pt
- Accent: Calibri Italic, 12-14pt

## Brand Voice

### Tone
- Professional yet approachable
- Authoritative but friendly
- Innovative and forward-thinking
- Clear and concise

### Language Principles
- Use inclusive language
- Avoid jargon when possible
- Be specific and concrete
- Show empathy and understanding
