  - 采购相关 → 采购管理/
  - 库存相关 → 库存管理/
  - 资产管理 → 固定资产/

  - 员工出差 → 出差管理/
  - 统计报表 → 报表统计/

  - 采购单据 → 采购管理/采购单_*.txt
  - 统计表格 → *.csv 文件
  - 工作日志 → */日志.txt
  - 月度报表 → 报表统计/月度报表/
  
按时间查找:
  - 2024年文件 → */2024/
  - 2023年文件 → */2023/
  - 本月文件 → 各模块的当月文件
