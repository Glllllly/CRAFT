# 快速上手销售管理多维表格系统，看这篇就够了！
多维表格销售管理系统旨在通过【客户数据查重】【收集表信息录入】【销售人员权限隔离】【自动化提醒关键事件】【自动化拉群】等方式，满足企业信息管理、潜在客户挖掘、数据统计分析的需求！
🔍在系统帮助中心，搜索相关功能关键字，即刻发现更多玩法！

# 【销售团队信息表】
在此表中，录入销售人员、负责区域、团队负责人等信息，方便在客户信息表中查找引用。

# 【客户信息表】
销售可以快速查看每个客户的详细信息，包括联系方式、商机情况、客户标签、跟进情况等等。
在分维度客户看板中，可以轻松地根据客户信息进行分类和筛选！
在客户信息表中录入客户信息，公式可自动判断是否有重复录入❗
新客户录入后，会自动创建专属沟通群，将客户负责人与对应团队负责人拉入，你可以在自动化流程中加入其它固定入群人员🙋‍
高阶玩法：可参考系统内关于自动化流程创建群组的教程。

# 【商机管理表】
通过将关联字段设置为单向关联类型，你可以将商机管理表中的商机信息，关联到客户信息表中的对应客户。
可通过看板视图查看不同阶段的商机，点击学习使用看板视图的基础教程！
新增的赢单信息将通过自动化，自动推送到对应销售团队群。
高阶玩法：想定制自己的赢单通知推送，可参考系统内关于自动化流程发送群消息的场景实践教程。

# 【客户跟进记录表】
销售跟进客户后，可以通过客户跟进记录表中的表单视图，填写跟进记录。
新增的跟进信息将通过自动化，自动推送到对应沟通群。

# 跨表查找引用：商机与跟进记录关联
商机可通过查找引用，与跟进记录互相关联。
①将“最近跟进时间”设置为查找引用字段，编辑该字段
②当客户跟进记录表中的关联客户字段等于商机管理表中的对接客户字段时
③引用客户跟进记录表中的跟进时间字段，且如果有多个匹配记录，引用跟进时间字段的最大值（最近跟进该客户时间）。
公式自动计算该商机未跟进的天数，超过一定时间自动化流程会提醒对应负责人及时跟进。

# 高级权限：控制角色权限范围
可通过开启高级权限设置，给客户负责人、团队负责人、管理者设置不同的自定义角色，控制协作者权限范围，如客户负责人仅可查看和修改自己名下的客户/商机。
高阶玩法：可参考系统内关于高级权限设置的教程。
