# 项目背景
产品发布会稳定性保障相关项目


# 产品功能
功能入口：内部功能平台入口
整体流程：
获取会议逐字稿
选择分析模板，发起流式分析
结果查看与分享

| 场景 | 功能描述 | 功能演示 |
| --- | --- | --- |
| 获取逐字稿 -智能工具链路 | 获取用户有权限的智能工具列表 用户选择工具后，加载会议逐字稿信息 |  |
| 获取逐字稿 -文档链路 | 获取用户有权限的智能纪要文档列表 用户选择文档后，通过第三方接口查询对应的会议逐字稿 通过权限接口查询文档内容 解析内容获取逐字稿信息 |  |
| 获取逐字稿 -文件链路 | 用户主动上传文件，前端通过SDK上传到存储服务，存储服务回调服务端接口完成鉴权与通知 服务端将文件传递给音视频处理中台 中台返回视频逐字稿信息 |  |
| 执行会议分析 | 用户选择分析模板（或自定义） 会议逐字稿 + 提示词 -> 大模型服务 服务端使用模型SDK轮询结果，流式展示到前端 |  |
| 分析结果分享 | 发送分享链接到内部群组 分享链接支持预览，生成包含结果截图的卡片 截图由第三方截图服务生成 |  |
| 查看侧边栏 | 查看历史分析记录 |  |
| 查看历史结果 | 查看单次历史分析结果 |  |
| 点赞/点踩 | 对分析内容进行反馈操作，用于产品优化 |  |
| 结果分享设置 | 修改结果的分享权限 组织内链接可见 内部平台登录后可见 |  |


# 系统依赖

## 基建部分

| 类型 | 说明 | 依赖等级 | 能否降级 |
| --- | --- | --- | --- |
| 服务集群 | 核心服务集群，仅线上环境，无测试/灰度集群 实例配置：多节点，12核16GB | 强 | 否 |
| 数据库 | 业务数据库，包含会议分析文档表、文档块表、会话表、截图表 | 强 | 否 |
| 配置存储 | 存储用户反馈、任务状态、分享配置、文档设置等信息 | 强 | 否 |
| 缓存服务 | 存储分享预览、流式链接统计、逐字稿缓存、会话锁等 | 弱 | 是 |
| 对象存储 | 存储逐字稿、音视频处理结果等文件 | 强 | 否 |
| 函数服务 | 生成分享结果截图，可降级为直接链接 | 弱 | 是 |
| 大模型服务 | 提供会议分析的模型能力 | 强 | 否 |
| 音视频处理服务 | 提供文件转逐字稿能力 | 强 | 否 |
| 配置中心 | 存储分析模板、流式输出、资源绑定等配置 | 强 | 否 |
